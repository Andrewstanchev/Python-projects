# 🛒 Retail Sales Analysis

## Project Overview

This project explores retail sales data using Python. It includes full-cycle data cleaning, KPI calculation, and visual analysis across countries, regions, and product categories. The goal is to identify sales patterns and regional performance insights.

## Data Sources

- `events.csv`: transactional data (orders, dates, units, prices)
- `products.csv`: product categories
- `countries.csv`: country metadata (region, sub-region)

## Key Steps

- Handled missing values and standardized country codes
- Merged datasets for enriched context
- Calculated core metrics: total sales, average unit price, units sold
- Visualized:
  - Sales by country and region
  - Product category distribution
  - Channel performance (online vs offline)
  - Priority-based sales segmentation

## Tools & Libraries

- Python: `pandas`, `numpy`, `matplotlib`, `seaborn`
- Environment: Google Colab

## Sample Outputs

- Cleaned dataset with no missing values
- Multiple visualizations (barplots, heatmaps, distribution plots)
- Insights into regional sales trends and product performance
