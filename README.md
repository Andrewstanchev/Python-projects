# 🛒 Retail Dataset Exploration (Project 1)

🎯 Цілі проєкту:
- Перевірка якості даних: пропуски, дублікати, типи
- Об'єднання трьох джерел: події замовлень + продукти + країни
- Побудова ключових метрик: прибуток, кількість замовлень, сезонність
- Візуалізація поведінкових патернів: час доставки, дні тижня, місяці, регіони


## 📊 Основні аналітичні блоки:
- ✔️ Cleaning: обробка `NaN`, датаформати, дублікати
- ✔️ Метрики: `Total Revenue`, `Units per Order`, популярність категорій
- ✔️ Геоаналіз: по країнах і регіонах
- ✔️ Канали: онлайн vs офлайн
- ✔️ Сезонність: по місяцях, днях тижня, по окремим категоріям

## 📈 Висновки:
- 📌 Найбільший прибуток: категорія `Cosmetics`, країна `Andorra`
- 📌 Найкоротша доставка — в Хорватію, найдовша — в Угорщину
- 📌 Сезонні патерни сильно варіюються по країнах
- 📌 Відмінності у поведінці користувачів по днях тижня для різних продуктів
